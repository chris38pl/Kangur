## User-facing (What users see)

After upgrade, a **bottom toast** → tap opens **What's New** (`/whats-new`). Full bullets in `1.0.3.json` (PL/EN). Summary:

1. **Lists from previous shopping for everyone** — no Premium paywall on this path.
2. **Deterministic merge** — combines products from recent lists (no AI / no credits on this step); swipe keep/reject → new list.
3. **Premium** still means deeper history + unlimited AI credits for import (screenshot / text / meal).
4. **Composer keyboard UX** — focusing a field in AI / recipe / manual-add scrolls that section so the header, fields, and CTA stay visible (sticky start-shopping bar hides while typing).
5. **Purchase cancelled sheet** — dismissing Play purchase shows a branded bottom sheet instead of a raw “User cancelled” alert.
6. **Meal shared-ingredient notes i18n** — cross-meal notes use localized “for … and …” (not hardcoded Polish `na` / `i`).

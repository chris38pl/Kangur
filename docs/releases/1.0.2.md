## User-facing (What users see)

After upgrade, a **bottom toast** (kangaroo icon + “Updated to version 1.0.2” + “Tap to see the details”) → tap opens **What's New** (`/whats-new`). Full bullet list for this release is in `1.0.2.json` (PL/EN). Summary:

1. **Smoother shopping in the store** — the list reacts right away even when the network is weak.
2. **Cleaner swipes** — no leftover colored strips after mark bought / not available.
3. **What's New toast** after update — tap for release details.
4. **Faster new lists** — from Home / FAB you land straight on the list form (honest “creating…” skeleton while we set things up).
5. **In-app feedback** — send an opinion or report a problem (optional photo).
6. **Smarter shelves** — pantry, spices, sauces, and better product placement.
7. **Lists from previous shopping** — suggestions without guessed piece counts; quieter review (no merge blurbs).
8. **Clearer AI downtime** — branded screen when import is temporarily unavailable.
9. **Reliability** — first-login home workspace, Android push wiring, finish-shopping summary, Lists sync badge.

## User-facing (What users see)

After upgrade, a **bottom toast** → tap opens **What's New** (`/whats-new`). Full bullets in `1.0.4.json` (PL/EN). Summary of product changes vs 1.0.3:

1. **List status clarity** - waiting / shopping / finished badges + left accent bars on Home & History; finished lists open in preview with restore / repeat.
2. **Faster manual add** - product catalog autocomplete (~273 common groceries, 10 locales); tap suggestion → add + toast; amount + note on one row.
3. **List edit polish** - sort items by category vs date (icons next to “Items”); sticky CTA ↔ success toasts (add / edit / delete / sort / AI batch); category order section under items; finished lists lock AI / recipe / manual add.
4. **History-merge review** - checkbox list like meal proposal (all selected by default) instead of swipe keep/reject.
5. **Shopping browse mode** - toggle aisles ↔ flat full list; tap cycles pending → bought → unavailable; preference saved per user; progress card stays sticky.
6. **AI uses** - free lifetime bucket default **10** (was 15); history-merge costs **1** use (same meter as other AI actions).
7. **Reliability** - no washed-out / ghost overlay right after create; AI credit banners refresh after use; status taps no longer flicker under rapid clicks; favorites no longer bump list `updatedAt`.
